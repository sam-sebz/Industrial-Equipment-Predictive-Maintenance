# PRD

## Goal
Predict equipment failure risk from sensor readings and make the result traceable through an API and history store.

## Users
Maintenance engineers, reliability analysts and plant operations teams.

## MVP
1. Enter sensor readings
2. Generate failure probability
3. Convert probability to low, medium or high risk
4. Store prediction history
5. Display model metrics

## Success criteria
Reproducible training, validated API input, persistent prediction history and documented evaluation metrics.

## Out of scope
Production plant integration, cloud infrastructure and live sensor ingestion.
